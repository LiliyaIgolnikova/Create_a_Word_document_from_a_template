# Create_a_Word_document_from_a_template
**Создание документа Word с помощью шаблона и заполнения полей на C#**
# Стек технологий:
- С#
- Microsoft Visual Studio
- Библиотека Microsoft.Office.Interop.Word
- Microsoft Word
# Как запустить проект:
Запустить файл "WindowsFormsApp1.sln"
# Возможности программы:
Создает готовый документ Word с помощью шаблона и полей, которые заполняет пользователь
